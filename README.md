# Telegram Converter Bot

A simple Telegram bot to convert images to PDF, PDF to images, and compress both PDFs and images. Built with Python and hosted on Render.

## Features
- `/img2pdf`: Convert one or more images (JPG, PNG, etc.) to a single PDF.
- `/pdf2img`: Convert a PDF to images (PNG files or ZIP if multiple pages, up to 10).
- `/compress [high/medium/low]`: Compress images or PDFs (specify quality or bot will ask).
- `/help`: Show usage instructions.

## Prerequisites
- Python 3.11+
- Telegram Bot Token from @BotFather
